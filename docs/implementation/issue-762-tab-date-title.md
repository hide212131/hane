# Issue #762 実装設計・引き継ぎ

状態: 実装準備（未実装・未検証）。この PR は設計と引き継ぎだけの準備 PR で、Claude の実装を待つ。

## 目的

日付入りノートのタブ名をサイドバーのファイル名本文と揃える。`2026-11-22_テスト.md` はタブに `テスト` と表示する。

## 変更内容と手順

1. `crates/ui/src/view/sidebar.rs` の `display_file_name` を `pub(super)` にし、親モジュールの `file_tab_display_name` から再利用する。末尾の `.md` は ASCII の大文字小文字を区別せずに除去する。`.MD` や `.Md` も対象とし、名前が拡張子だけの場合は元の文字列を保持する。
2. 拡張子除去後の名前を `split_file_name_for_badge` に渡す。最初の有効な日付が見つかり、`remainder()` が空でなければ、その結果をタブ名にする。日付に隣接する区切り文字の除去と、前後の文字列の連結は既存 API に任せる。
3. 有効な日付が見つからない場合は、拡張子除去後の名前を表示する。

変更は `crates/ui/src/view.rs` の `file_tab_display_name` と単体テスト、および `crates/ui/src/view/sidebar.rs` の `display_file_name` の可視性に限る。

## 日付だけの場合

`remainder()` が空なら、タブに識別できる名前を残すため、拡張子除去後の名前に戻す。`2026-11-22.md` は `2026-11-22` と表示する。日付はファイル名の表記のまま保持する。

## テスト

`crates/ui/src/view.rs` の既存の `#[cfg(test)] mod tests` に、`file_tab_display_name` を直接呼ぶテーブル駆動の単体テストを追加する。

| ケース | 入力 | 期待表示 |
|---|---|---|
| 先頭の日付 | `2026-11-22_テスト.md` | `テスト` |
| 途中の日付 | `週報_2026-1-2_下書き.md` | `週報 下書き` |
| 末尾の日付 | `週報_2026-11-22.md` | `週報` |
| `YYYYMMDD` 形式 | `20261122_テスト.md` | `テスト` |
| 無効な日付 | `2026-02-30_テスト.md` | `2026-02-30_テスト` |
| 日付なし | `テスト.md` | `テスト` |
| 日付だけ | `2026-11-22.md` | `2026-11-22` |
| 大文字の拡張子 | `2026-11-22_テスト.MD` | `テスト` |
| 拡張子だけ | `.md` | `.md` |

## 影響範囲と対象外

`file_tab_display_name` の呼び出しは `header_element` のタブ描画の1か所。`short_label()` はタブ描画と `view/a11y_links.rs` のアクセシビリティ用文書名で使われている。ウィンドウタイトルや別のセッション一覧からの参照はない。

変換はタブ描画時に限定する。`short_label()`、サイドバーの描画、実ファイル名とパス、タブの未保存マーク ` *`、ホバー時のフルパス表示は対象外とする。
