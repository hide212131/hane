## 状態

フェーズ1（インラインタグ）は実装済み。検証結果は PR の evidence に別途記録する。フェーズ2（単独行ブロック）は未着手。

## 設計

設計書は `docs/implementation/issue-757-html-design.md`（このフォルダ内）。設計担当は Codex GPT-6.2 Sol、基準は `main` の `411c8089`。2026-11-22 にユーザーが設計を承認した。

## フェーズ分け

実装は2フェーズに分けて進める（1回の実装が大きくなりすぎないようにするため。各フェーズのマージで Issue は閉じず、両フェーズの完了で閉じる）。

- フェーズ1: インラインタグ（`b`/`strong`、`i`/`em`、`s`/`del`/`strike`、`code`、`a`）を、段落・見出し内の同じ物理行で正しく閉じたペアに限り、等価な Markdown 装飾として表示する
- フェーズ2: 単独行ブロック（`p`、`h1`–`h6`、`hr`）を段落・見出し・区切り線として表示する

## 実装の要点（両フェーズ共通）

- タグはマーカーと同じ開示モデル: 通常は隠し、カーソル・選択・IME・検索一致が触れている間だけ原文を展開する。開閉で文書のバイト・revision・dirty・undo は変えない。閲覧モードは常に非表示、プレーンモードはソース表示のまま
- 壊れたタグ（閉じ忘れ・交差・異名ペア）は要素ごと原文表示に倒す。属性は `a` の `href` のみ有効で、検証済みの絶対 http/https 以外は原文表示
- 許可リスト方式。`script`/`style`/`iframe`/`form` は描画しない。走査には上限（設計書参照）を設け、超過時は原文表示
- 実装の置き場は設計書のとおり: pulldown-cmark の範囲を正本に `crates/markdown/src/html.rs` で軽いタグ走査を行い、検証済み要素情報を parse 結果に付加する。表示は既存の開示・SourceMap・高さ同期を再利用し、`BlockIndex` の行数は物理行数のまま

## 対象外

- `img`、`br`、`u`、`sub`、`sup`、`kbd`、`details`/`summary`、`div`/`span`、`blockquote`、`ul`/`ol`/`li`、`pre`、表系タグ（原文表示のまま）
- フェーズ1ではリスト・引用・表セル内のインラインタグも対象外
