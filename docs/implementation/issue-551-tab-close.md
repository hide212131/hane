## 依頼時のIssue契約

## 目的

編集画面上部のファイルタブを、ショートカット、中クリック、右クリックメニューから安全に閉じられるようにする。

## 範囲と仕様

- macOSは `Cmd+W`、Windowsは `Ctrl+W` で選択中のタブを閉じる。ウインドウ全体を終了させず、既存の最後のタブを閉じる扱いを維持する。
- タブの右クリックメニューへ「タブを閉じる」を追加する。選択中かどうかにかかわらず、右クリックしたタブを対象とし、無題文書にも使える。既存のメニュー項目を維持する。
- 中クリックは #411 / PR #416 で採用済み。再実装せず、今回追加する入口とともに既存の `request_tab_close` と保存確認の経路を使う。
- 未保存内容を無確認で破棄しない。保存して閉じる／キャンセル、名前未確定文書の保存先選択、保存失敗・保存先選択取消を既存契約に合わせる。
- 非選択タブを閉じても不要に選択を切り替えない。メニュー表示後のタブ消滅・同じIDの文書差し替え・Work folder切替では別文書を閉じない。
- キーの適用範囲は既存タブ移動actionと入力先判定に合わせる。設定画面・本文以外の入力やIME変換を横取りしたり、変換中内容を消失させたりしない。閲覧モードが採用された場合も閉じる操作として利用できるよう整合させる。

## 受入条件

- [ ] 両OSで対応ショートカットから選択タブを一度だけ閉じ、他タブの本文・選択・Undo/Redo・スクロールを壊さない。

- [ ] 3入口とも未保存確認を通り、キャンセル・保存失敗・Save As取消では文書と内容を保持する。空／1タブ／最後のタブ、連打、メニュー対象の失効を安全に扱う。
- [ ] ツールチップ表示中、狭幅、多数タブでも中／右クリックが届く。左クリックとタブ移動は維持する。
