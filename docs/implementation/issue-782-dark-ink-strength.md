# Issue #782 実装設計: 乾くインクのダークテーマ強化

## 目的

#779 の「乾くインク」について、ダークテーマでは文字の乾きが見えない問題（実測で確定直後の差が約 +11/255）を直す。ダークテーマのときだけ文字側の効きを 2 倍にし、標準で約 +26/255（理論値）まで引き上げる。

## 実測の根拠

- 対象: v0.54.0（main 49cca06e）、papa の GUI 実走、ダークテーマ・濃さ標準・速さ標準（60 秒）。
- IME 確定した行の文字芯の輝度は、確定直後が対照行（既存の乾いた行）比で約 +10.7、約100秒後に対照行と一致した。記録・4段階・タイマー・基本色への復帰はすべて正常。
- ダークテーマの文字色 0xe8e5df は OKLab 明度 0.923。ΔL 0.04 では sRGB で (232,229,223) → (245,242,236) の +13 段階しか動かない。ライトテーマの文字色 0x262626 では同じ ΔL でも相対変化が大きく、実測でも明瞭だった。

## 変更

- `crates/ui/src/ink.rs` の `ink_color` で、`dark == true` のとき効きを 2 倍にする。定数として理由とともに置く（例: `DARK_DELTA_L_FACTOR: f32 = 2.0`）。
  - 弱: 0.025 → 実効 0.05 ／ 標準: 0.04 → 実効 0.08 ／ 強: 0.06 → 実効 0.12。
  - 明度は `shift_lightness` が 1.0 でクランプする。強の最湿時にほぼ白くなるのは許容する。
  - `ink_color` の doc コメントを、ダーク時に倍率が掛かる現在の仕様に合わせて更新する。
- 帯（`band_color` / `band_delta_l`）は変更しない。帯は現状で視認でき、テーマ間の釣り合いも取れている。
- `InkParams`、設定（`DryingInkStrength` の表・キー・設定画面）、段階数、乾き時間、台帳の記録方法は変更しない。倍率は描画時の色計算の中だけに閉じる。

## テスト

- `crates/ui/src/ink.rs` の単体テストに追加する:
  - ダーク・レベル最大・delta_l 0.04 の結果が、明度 +0.08 相当であること（基本色 0xe8e5df を使い、結果の OKLab 明度で検証する）。
  - ライト・レベル最大・delta_l 0.04 の結果が従来どおり明度 −0.04 相当であること。
  - レベル 0 ではダークでも基本色がそのまま返ること。
  - 既存の「明度だけが動く（a/b が変わらない）」テストが、倍率の後も両テーマで通ること。
- 既存の ink / drying_ink 関連テストがすべて通ること。

## 対象外

- 帯の強さ、乾き時間、段階数の変更。
- ライトテーマの効きの変更。
- 設定画面への数値表示の追加。
- #779 の不変条件（文書・履歴・選択・IME 状態に影響しない、OFF で従来描画と一致）の変更。

## 受入条件

- 上記の単体テストが追加され、`cargo test -p hane-ui ink` 相当で通る。
- ワークフロー検証（test / clippy）が通る。
- papa の GUI 実測（ダーク・標準）で、確定直後の行の輝度差が対照行比で +18 以上、約100秒後に対照行と一致する。
