# Issue #99: ATX見出しの実装・検証記録

2026-09-09、macOSで `cargo build -p hane --features timing-probe` の実アプリを起動し、Computer Use経由のクリック、ドラッグ、キー入力で確認した。普段の文書・設定とは別の検証ファイルと `HANE_STATE_DIR` を使用した。ビルド識別情報とテストログは [証拠ディレクトリ](2026-09-09-atx/) に保存。

## 変更と解析の根拠

- CommonMark 0.31.2 §4.2の仕様例62〜79をJSONのまま取り込み、parserのHTML結果とHaneの見出しレベルを照合。追加でタブ、引用・リスト内、コード内タブ、Setextの非回帰を検証。
- 見出しかどうかは既存のpulldown-cmarkが決定する。開き側の空白とタブをマーカーに含め、閉じ側はparserの最後の子ノード以後の範囲から求める。原文の正規化・書き換えは行わない。
- 閉じ側マーカーを非編集中は隠し、見出しにカーソルがあると開き側と一緒に表示する。強調・コード等は既存の「編集中の構文だけ開く」方針を維持。
- 引用・リスト内の見出しもレベル別表示を適用する。コンテナの索引とレイアウト方式は既存のまま。
- pulldown-cmark 0.13.4は閉じ側直前・末尾のタブを空白として扱わなかった。独自parserに置き換えず、同版を同梱して `firstpass.rs` の空白判定2行だけ修正。[限定パッチの説明](../../../vendor/pulldown-cmark/HANE-PATCH.md) に上流差分と撤去条件を記録した。
